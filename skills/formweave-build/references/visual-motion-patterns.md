# 桌面材质、光影与分层过渡

适合有展示空间的设备总览、素材库或项目入口；不是每个 Windows 工具都要有玻璃、动态壁纸或大面积留白。密集操作面保留稳定底色与现有密度。先定哪些元素需要保持原位，再决定哪些元素需要动。

| 要表达什么 | 视觉做法 | 复验 |
|---|---|---|
| 同一套深浅主题 | 共用构图、控件位置与语义。浅色靠雾面底、细亮边和软阴影，深色靠有下限的烟灰表面、局部边缘光与对比；不要只反转颜色。背景、工具层、内容层分别管理。 | 同一视窗、同一状态比较深浅。取背景最亮和最暗时核对文字、焦点与选中；关闭透明或高对比度时仍能读内容。 |
| 预览当前对象但不确认选择 | 悬停或键盘聚焦只更新独立预览面。图像、标题与状态可短淡入；卡片的布局和命中保持不变。离开恢复已选对象；快速横扫只保留最后一项，悬停不触发真实命令。 | 鼠标在 A、B 间切换，键盘到达同一信息；离开、取消或失焦后不残留旧对象预览。 |
| 同一对象换布局 | 少量卡片从原视图移到目标位置，详情按空间显隐；固定视图开关与工具栏。以对象标识复用卡片。开始或反向前读当前可见位置与尺寸，取消旧动画，再从当前画面过渡到新布局；不排队、不先跳到旧终点。 | 动画走到中途即反向；比较切换前后一帧是否跳位、是否重叠两份卡片、键盘焦点和最终选中是否保留。窄窗复杂布局可直接切换。 |
| 进入新层级或留在同层 | 跨层级可以用方向性过渡明确进退；同级标签保持外壳、侧栏和标题位置，只更新内容区。背景慢变化是最弱的一层，不参与导航。 | 快速切标签不影响标题、焦点和外壳。高频工作区、后台及减少动效时避免装饰循环；不靠动画结束事件决定业务终态。 |

可先试局部淡入 140–180 ms、少量卡片布局切换 220–280 ms；值不是原软件参数或强制规范。减少动效时从同一状态直接进入目标布局，保留选中、标签、文字和结果。网页演示只证明其浏览器表现；实际应用另查 Windows 高对比度、混合 DPI、系统设置和空闲开销。

## 原始观察与边界

2026-11-19 依据用户提供的 M HUB 2.0.0 两段本地录屏和同屏深浅静帧观察：设备总览中慢变高光、固定工具栏、卡片悬停预览；紧凑卡片与网格之间可见双向位移与缩放；跨页切换时背景延续，同级设置页仅变更内容。第二段录屏看到多次快速往返均能落到对应视图，未证明软件从中间帧连续反向、未读取实现或精确参数。M HUB 是本地桌面软件，与动效目录中的 Motion Hub 不是同一来源。本包仅借鉴视觉方法，不分发录屏、品牌、壁纸、产品图或原实现。
