# Windows 界面审查

包内相对路径均以本 SKILL.md 所在目录为基准。按材料和审查目标读取参考；不预先加载动效索引。

识别评审对象、目标用户、核心任务、系统和材料类型。没有材料时先索取截图、可访问原型或工程路径。按[桌面设计](references/desktop.md)走一遍主操作，再测试最可能影响任务的例外。手机设计参考按[版本依据](references/mobile.md)判断其桌面适用条件。

每条记录写明复现环境与步骤、截图位置或文件行、观察结果、用户影响、优先级、具体改法与复验方式。阻止完成/数据风险为高，明显妨碍效率为中，局部一致性为低；结合频率、可绕过程度排序。分开记录观察、推断与未覆盖项。只给截图时能评可读性、层次与状态表达，输入法、耗时和可访问树需要其他证据。交付审查报告。随后要求改动时先核对[确认单](references/agreement.md)。

审查过渡、加载或指针行为时，按[桌面动效决策](references/motion.md)复验触发、中断和降级。需追溯设计借鉴时按来源和 ID 查[双站索引](references/motion-index.md)。静态截图只支持对可见状态的结论。

报告先列最影响主任务的发现，再列未覆盖项。证据不足时给出需补充的材料和复验方法；没有发现问题也如实报告审查范围，不凑数量。审查完成以每个发现能定位、能解释影响且能复验为准。
