# Windows 界面预览

包内相对路径均以本 SKILL.md 所在目录为基准。先读桌面设计；移动转化、动效和来源索引仅在对应请求需要时读取。

数据密集型分栏任务可取用[单页库存预览](assets/inventory-preview.html)作为起点。直接用浏览器打开即可查看筛选、空状态和差异详情；其 72 条记录均为模拟数据。

确认载体与最重要的操作路径。按[桌面设计](references/desktop.md)选用实际数据密度和键盘路径。用户要求借鉴手机系统时再读[设计来源](references/mobile.md)。已有应用先看截图或源码；在独立预览目录创建静态图、单页 HTML 或框架原型，按用户目标选择一种。使用脱敏数据。

呈现主路径与至少一个影响设计的例外状态。验证实际可预览，说明入口、窗口尺寸、已接通的操作、模拟数据和需原生验证的部分。网页原型不能证明系统输入法、原生菜单、任务栏、拖放或多显示器表现。若请求转为改应用，先独立执行[确认单](references/agreement.md)。用户只要预览时保持预览范围。

制作动效预览时，从[桌面动效决策](references/motion.md)选择一条主操作；需要特定效果时按来源和 ID 查[双站索引](references/motion-index.md)。让预览可切换、可中断，并能在减少动效时呈现相同终态。

交付包含可打开的入口路径、复现步骤、已实际验证的状态和未接通的业务操作。例如差异详情可切换、筛选无结果可见；若没有浏览器或原生运行条件，明确说明仅完成静态检查，不宣称交互验证通过。
