# Windows 界面预览

包内相对路径以本 SKILL.md 所在目录为基准。在独立目录制作预览，载体按用户目标选择。

## 环境

需能写入独立预览目录；HTML 预览需浏览器，原生原型需相应框架。网页预览不能替代 Windows 原生验收。

## 执行

先确认最重要的操作路径和已有设计材料。按[桌面设计](references/desktop.md)安排数据密度、状态和键盘入口；使用脱敏或合成数据。静态图、单页 HTML、框架原型选择一种即可，不为统一形式生成多套产物。

呈现主路径及影响设计的例外状态，实际打开预览检查已接通的操作。已有应用先查看截图或源码；用户只要预览时保留该范围，转为修改应用时再核对[范围确认](references/agreement.md)。

## 交付

提供可打开的入口、窗口尺寸、复现步骤、已验证状态和模拟范围。HTML 预览不能证明原生输入法、菜单、任务栏、拖放或多屏行为；缺少运行条件时，说明只完成了哪些静态检查，不宣称交互已通过。
