# Windows 应用规划

包内相对路径均以本 SKILL.md 所在目录为基准。只读取当前决策需要的参考；不预先加载动效索引。

先检查当前项目、仓库指引、构建入口、界面和已有确认记录。对照[确认单](references/agreement.md)填写已知项，仅询问会改变方案的缺口。用[选型指南](references/frameworks.md)筛出两三个可行候选。分别交付架构、界面框架和代码组织的推荐、理由、代价及被排除的选项。涉及开源工程时按[复用记录](references/adoption.md)核实。

返回可在聊天中确认的方案和验收条件。用户只求咨询时直接回答；用户要实施且对方案明确确认后，沿用该范围。单独安装本技能也能完成整个规划。

涉及动效选型时，先用[桌面动效决策](references/motion.md)把业务目的、触发和验收写进方案，再按需查[双站索引](references/motion-index.md)。确认平台、交付范围和资源预算，保留已有架构。

交付时区分已知事实、建议默认值和待确认项，给出可复验的验收条件。例如“8 万行离线表格”应说明目标数据、筛选操作和测量方法；没有测量时不填写虚构的耗时。规划完成以用户能够据此决定范围为准。
