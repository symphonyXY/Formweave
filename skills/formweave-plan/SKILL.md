# Windows 应用规划

包内相对路径以本 SKILL.md 所在目录为基准。根据当前决策读取参考资料。

## 环境

可读取本地项目的编码 Agent；规划无需安装 GUI 框架。核对最新平台、依赖和许可证时需要网络。

## 执行

先查看项目指引、已有工程、运行入口和聊天中的确认记录。按[范围确认](references/agreement.md)整理已知约束，只询问会改变方案的缺口；已有确认直接沿用。

用[框架选型](references/frameworks.md)判断现有技术栈是否满足约束。需要选型或迁移时，比较足以支持决策的候选，分别说明进程架构、界面框架和代码组织的推荐、代价与验收方法。现有方案已满足要求时，说明保留理由，无需凑出其他候选。

只交付用户所需的咨询或方案。方案包含待决定的差异与建议默认值；用户明确批准实施范围后，后续工作沿用该范围。

## 交付

给出可在聊天中确认的方案、可复验的验收条件及待验证项，区分事实与建议。例如“8 万行离线表格”要明确数据规模、筛选操作和测量方法；没有实测就不填写耗时结论。交付应足以让用户决定范围。
