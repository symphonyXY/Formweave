# 为 Windows 桌面任务选动效

先说清用户刚做了什么、画面要解释哪个变化。普通查询、筛选和重复录入可以直接更新。需要候选效果时，从下表选一个业务目的，再在[双站逐项索引](motion-index.md)中按策略名、中文名或原始 ID 查找。记录“来源＋ID → 桌面改法 → 可复验结果”。网站标注的秒数、触发器和可调参数描述的是演示；下表的处理是织形建议。

| 索引策略 | 用在什么地方 | 实施与降级 |
|---|---|---|
| 内容切换 | 点选库存行后右侧详情换成新物料；打开一块新内容 | 立即写入最终编号、库存和可访问名称，只对新内容做一次短淡入。旧动效可取消。减少动效时一步呈现。频繁切换的大表本身保持稳定。 |
| 层级开合 | 抽屉、对话框、折叠检查器、返回上一层 | 入场方向对应面板归属，离场成对。展开先安排焦点和可点击区域，收起时焦点回到触发控件。反复展开/收起应从当前位置改向。窄窗改变布局时保留键盘入口。 |
| 控件反馈 | 按钮按下、开关切换、筛选标签和链接 | 先响应输入、更新选中或忙碌语义，细小色差、下划线或局部涟漪辅助确认。按键与点击走同一命令；不移动按钮热区。系统高对比度下保留边框、焦点及开关文字。 |
| 任务等待 | 打开数据源、首次加载未知耗时的列表 | 只在确有等待时显示骨架或不确定指示，已知行占位保持原尺寸。数据返回、取消、失败或窗口关闭均终止循环。减少动效时用静态占位和“正在加载”。 |
| 数值进度 | 批处理数量、标量参数、滚动位置、统计摘要 | 业务层直接提供真值。工作完成数、视口位置和滑块值分别绑定各自来源。数值插值只用于可选展示；百分比、辅助技术读数和取消结果始终反映实际状态。库存表的可复制数字立即落定。 |
| 操作回执 | 校验失败、保存成功、状态改变 | 错误定位到字段并保留输入，完成后显示文本和数量。强调最多一次；失败不循环抖动，成功不强加庆祝。重复操作的回执只对应当前任务。 |
| 定点操控 | 专用画布中拖动、缩放、放置，检查器显示上下文命令 | 直接操控阶段位置跟手；松手后才考虑吸附。键盘、菜单和右键提供等价动作。保留系统光标、文件拖放、文本选择及多选语义；拖出窗口、Esc 和焦点丢失要清理临时态。 |
| 分组呈现 | 首次进入低密度面板，分组展示少量内容 | 仅为可见分组错开，不为每条记录建立动画或定时器。输入、阅读顺序与可点击时机不依赖动效顺序。普通虚拟列表滚动和搜索结果直接复用行。 |
| 专项展示 | 摄影视图、图形编辑器、数据可视化、明确获批的引导或品牌区域 | 先说明需要表达的对象和触发条件。物理、3D、滤镜、粒子和滚动驱动默认不进入盘点表、表单及文件选择器。若功能确实依赖这种绘制，限制表面与并发，提供静态或软件渲染路径。 |
| 装饰留档 | 字符故障、循环背景、光标轨迹、磁吸按钮等演示 | 常规工作区保留静态文字、固定热区、系统光标和稳定背景。需要单独的品牌展示任务才重新评估；不向现有技术栈引入渲染库来重现这些样式。 |

## 将一条记录转成实现

- **Qt Widgets 盘点。** 候选 LuckyMaomi `crossfade`。当前样例用 `QPropertyAnimation` 对详情名称做单表面淡入。点选记录时先更新模型与文本，停止旧动画后开始新反馈，不叠加两个详情树。Qt 原生文件拖放、焦点环与命中区域单独回归。
- **WPF 数据表。** 候选 Motion.Lab `highlight-sweep`。对于一万行 DataGrid，将其收敛为选中行和固定回执；业务若需要过渡，只在固定回执容器上使用可替换的 Storyboard，优先 Opacity / RenderTransform。避免动画修改行高触发虚拟化容器反复布局。WPF 样例现行行为是即时文字更新。
- **Electron 文件选择。** 候选 Motion.Lab `button-press`、LuckyMaomi `scale-in`。按下后立即进入选择中，原生对话框退出再依据 IPC 结果更新回执。短淡入可以替代整个窗口缩放；渲染层取消先前动画，按系统减少动效设置跳过。取消和失败均归还按钮焦点。无需把用户文件交给网页特效库。
- **两个容易混用的条目。** LuckyMaomi `scale-out` 适合讨论关闭；Motion.Lab `scale-out` 是从放大到正常的入场。LuckyMaomi `progress-bar` 是循环演示，迁移为批处理反馈时必须改绑完成数；Motion.Lab `scroll-progress` 的来源是滚动位置，不能用作任务进度。

## 参数与验收

本仓库 Qt 详情淡入为 140 ms，HTML 详情为 150 ms，可作为类似局部切换的起点。测量并分别记录输入到状态更新、过渡时长、滚动掉帧和空闲消耗。快速连点、长任务取消、高 DPI、窗口缩放、切后台、关闭及系统减少动效分别验收。把时长归零时仍应得到正确终态、焦点和文字；不要仅依赖动画结束事件提交数据或释放资源。

评审时要能复现：选 A 后立即选 B、C，最后只见 C；刚启动批量校验就取消，数量来自执行器；从文件选择器取消后再用键盘打开，焦点可达。截图可以检查层次、对比和选中态，时序、中断、真实拖放和帧率各需相应运行证据。其他框架沿用同样的任务语义，适配与性能按实际项目另验。
